# مواصفات المستوردات (Importer Specifications)

هذه الوثيقة تحدد آلية استيراد الفتاوى من المصادر الرسمية. لا يُسمح بإضافة أي مصدر برمجيًا قبل توثيقه والموافقة عليه في هذا الملف.

## القاعدة الذهبية (Source of Truth)
لا يتم توليد الإجابات، ولا إعادة صياغتها، ولا تفسيرها. تُجلب الفتوى بالنص الحرفي للمصدر، وتُعرض مع إشارة واضحة للرابط الرسمي إن وجد. كل فتوى مستوردة جديدة تدخل النظام بحالة `pending` حتى يتم مراجعتها أو اعتماد المصدر بشكل موثوق.

---

## المصدر 1: الموقع الرسمي للشيخ ابن باز (مثال)
- **اسم المصدر**: الإمام عبدالعزيز بن عبدالله بن باز.
- **الرابط الرسمي**: https://binbaz.org.sa/
- **طريقة الوصول (Access Method)**: (سيتم تحديدها لاحقاً: API إذا توفر، RSS، أو ملفات XML/JSON).
- **شروط الاستخدام**: يسمح الموقع بنشر الفتاوى بشرط عزوها لمصدرها دون تعديل في النص.
- **تاريخ المراجعة**: 2026-07-19
- **آلية التحديث**: يتم الاستعلام عن الفتاوى الجديدة يومياً عبر BullMQ (الـ Queue).
- **آلية التحقق**: الـ Normalizer يقوم بتنظيف الـ HTML، والـ Duplicate Checker يتحقق من عدم وجود `slug` الفتوى مسبقاً.

## المصدر 2: Mock Importer (للتطوير)
- **اسم المصدر**: Mock JSON Data
- **الرابط الرسمي**: N/A
- **طريقة الوصول**: قراءة ملف محلي `test-data.json`.
- **الهدف**: اختبار الـ Pipeline كاملاً دون الاعتماد على الشبكة.
